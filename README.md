# Тихая комната

Личный блог [l4iniwakura](https://l4iniwakura.github.io/blog/) на Jekyll и GitHub Pages.

Главная `/` содержит единственную ссылку на блог. Блог живёт в `/blog/`.

## Новая запись

1. Скопируйте содержимое [`POST_TEMPLATE.md`](POST_TEMPLATE.md) в новый файл `_posts/YYYY-MM-DD-short-name.md`. Можно прямо через GitHub → Add file → Create new file.
2. Измените название, дату (в том числе в имени файла), описание и каталог в `categories`. `notes` — ключ каталога «Заметки». Сам `POST_TEMPLATE.md` оставьте как образец: он исключён из публикации.
3. Напишите текст в Markdown и сохраните в `main`.
4. Дождитесь зелёной сборки `pages build and deployment` во вкладке Actions.

```yaml
---
title: "Название записи"
description: "Короткое описание для списка записей."
date: 2026-10-16 12:00:00 +0700
categories: [notes]
tags: [наблюдения]
comments: true
---

Текст статьи.

## Подзаголовок

Продолжение текста.
```

Для немедленной публикации используйте текущую или прошедшую дату, включая время. Будущая дата не означает автоматическую публикацию по расписанию: нужна новая сборка после наступления даты. Для черновика добавьте `published: false`. URL создаётся из имени файла: `short-name` → `/blog/short-name/`. После публикации сохраняйте имя или задайте постоянный `permalink`, поскольку комментарии giscus связаны с путём.

Демо и подробные примеры: [`_posts/2026-10-16-a-light-in-the-window.md`](_posts/2026-10-16-a-light-in-the-window.md).

## Каталоги

Каталоги описаны в `_data/catalogs.yml`: `notes`, `digital`, `slow`. Поле `categories` в статье задаёт её каталоги; допускается несколько. Новые ключи автоматически появляются на странице каталогов. Чтобы дать им красивое название, описание и ссылку с главной страницы блога, добавьте запись в `_data/catalogs.yml`.

## Комментарии

giscus использует Announcements в Discussions этого репозитория. Настройки в `_config.yml`, вставка в `_includes/comments.html`, цветовая тема в `assets/giscus.css`. Приложение [giscus](https://github.com/apps/giscus) должно быть установлено для этого репозитория. `comments: false` отключает комментарии для конкретной записи. RSS: `/blog/feed.xml`.

## Локальный запуск

Нужны Ruby и Bundler:

```sh
bundle install
bundle exec jekyll serve
```

Откройте `http://localhost:4000/blog/`. GitHub Pages собирает сайт автоматически из `main`, отдельный workflow не нужен. Файл `.nojekyll` добавлять нельзя: он отключит обработку шаблонов.

## Оформление и ресурсы

CSS: `assets/blog.css`. Небольшой JS (`assets/blog.js`) отвечает за приглушение света и поиск в архиве. Без JS статьи и каталоги доступны; комментарии требуют JS. Учитываются reduced motion и мобильные экраны. Шрифты Golos Text и Literata хранятся локально, лицензии OFL — рядом с файлами шрифтов. Иллюстрация `assets/quiet-room.webp` создана встроенным ImageGen специально для блога; краткий промпт: «Камерный вечерний уголок для чтения: оранжевая лампа-гриб, зелёный ковёр, папоротник и растения, фактура книжной иллюстрации». Нет аналитики и тяжёлых анимационных библиотек.
